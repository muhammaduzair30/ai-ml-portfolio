## 🚀 Quickstart & Local Setup

### Prerequisites
- [Node.js](https://nodejs.org/) (v18.x or higher)
- [npm](https://www.npmjs.com/) or [pnpm](https://pnpm.io/)

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/muhammaduzair30/ai-ml-portfolio.git
   cd ai-ml-portfolio
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Configure Environment Variables (Optional):**
   Copy `.env.example` to `.env`:
   ```bash
   cp .env.example .env
   ```
   Add your free Groq API key:
   ```env
   VITE_GROQ_API_KEY=your_groq_api_key_here
   ```
   *(Note: The portfolio includes an intelligent local fallback simulator, so the chat agent works seamlessly even without an API key!)*

4. **Start Development Server:**
   ```bash
   npm run dev
   ```

5. **Build for Production:**
   ```bash
   npm run build
   ```

## 🌐 One-Click Deployment

### Deploy to Vercel
1. Push this repo to your GitHub account.
2. Go to [Vercel](https://vercel.com) and click **"Add New Project"**.
3. Import this repository.
4. Add environment variable:
   - `VITE_GROQ_API_KEY`: `your_groq_api_key`
5. Click **Deploy**.

### Deploy to Netlify
1. Go to [Netlify](https://netlify.com) and click **"Add new site" -> "Import an existing project"**.
2. Select your repository.
3. Build command: `npm run build`
4. Publish directory: `dist`
5. Add environment variable `VITE_GROQ_API_KEY`.
6. Click **Deploy Site**.
